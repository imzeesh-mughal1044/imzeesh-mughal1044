"Python" "Pandas" "NumPy" "Matplotlib" "Seaborn" "Django" "PostgreSQL" "Supabase"

🛍️ CONFLUMIX — Unified Multi-Mode Marketplace

A university project built around a different approach to marketplace software: multiple forms of value exchange inside one platform.

CONFLUMIX brings together:

- 🛒 New Product Marketplace
- ♻️ Reuse Marketplace
- 🧑‍💻 Task & Skill Marketplace
- ❤️ Donation Marketplace
- 📍 Shared local discovery

The platform uses a common data ecosystem involving:

Users → Listings → Tasks → Resources → Supply/Demand → Location → Matching → Transactions → Reviews

The project also connects directly with Data Science through marketplace data analysis, including:

- Supply and demand analysis
- Product and reuse trends
- Skill demand vs availability
- Donation matching analysis
- Local demand patterns
- Cross-market relationships

Core technologies:
"Next.js" "React" "TypeScript" "Tailwind CSS" "ASP.NET Core" "C#" "PostgreSQL" "Supabase" "Python" "FastAPI" "Pandas" "NumPy"
